An entry for the [make.fun bounty "Make the AI judge feel curious"](https://make.fun/bounty/make-the-ai-judge-feel-curious-20261122-2311).

The program (`main.ts`, Node 22) writes one short text to `/output/entry.txt`:
a lighthouse keeper who never lights the lamp, climbing the stairs every
night to stand by the dark glass and listen to the sea ask the same question
it asked the night before. One quiet image, one question left open.

Run it with `node main.ts`.
